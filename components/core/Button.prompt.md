Primary action button — condensed uppercase Oswald label, square edges, hard press.

```jsx
<Button variant="primary" size="md">Read the story</Button>
<Button variant="ghost" as="a" href="#work">View all work</Button>
```

Variants: `primary` (orange), `secondary` (black), `ghost` (outline → fills black on hover). Sizes: `sm` / `md` / `lg`.
